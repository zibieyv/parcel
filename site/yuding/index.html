它是干什么的

闲鱼没有公开的“某人在线”接口。鱼盯用无障碍读屏，读你指定用户主页/聊天页上的文字（昵称、刚刚来过、N分钟前来过、在线 等），命中就响铃、振动、用中文念「某某上线了」。不抓包、不改闲鱼、不 root。

按顺序打开目标主页，读屏 + 下拉刷新，循环
你自己停在对方页面，App 只负责盯
默认只发通知；响铃/振动/语音在设置里开
不点屏幕；闲鱼露在屏幕上就能读，视频小窗盖着也行

界面

目标列表

支持带 userId 的主页链接、纯数字闲鱼号、m.tb.cn 分享短链；短链可一键解析成主页链接。

上线记录

上线 / 下线都会记一条，最多 300 条，全在本机。

黑屏挂机

屏幕亮度降到 0 继续读屏和刷新，通知栏可恢复；最长 3 小时自动恢复。

短链解析

只能拿到 m.tb.cn 短链也能用：解析出 userId 后自动填成主页链接。

安装 / 第一次用

  1. 装 APK
    微信发到手机，或本页直接下载；允许未知来源。
  2. 允许受限设置
    设置 → 应用 → 鱼盯 → 右上角 ⋮ → 允许受限设置（Android 13+ 必须，否则无障碍被拦）。
  3. 开无障碍
    设置 → 无障碍 → 鱼盯 → 打开。
  4. 开悬浮窗（可选）
    设置 → 应用 → 鱼盯 → 其他权限 → 显示在其他应用上层，观察时左上角会有状态条。
  5. 加目标
    闲鱼里打开对方主页 → 分享 → 复制链接 → 鱼盯「目标」→ ＋ → 粘贴。短链点「解析短链」。昵称要和闲鱼上一致。
  6. 先手动驻留试一次
    停在对方主页 → 开始观察 → 等「刚刚来过/在线」出现，确认响铃和播报正常，再切自动轮询。

已知限制

只认文字，不认绿色圆点；没有截图 OCR 兜底（长时间识屏费电，当前版本走读屏）。自动跳页依赖无障碍，ColorOS 重启/清后台后可能自动关闭，重新打开一次即可。观察期间屏幕会保持常亮；锁屏后读不到。不能自动发消息 / 自动拍下。

“手动 / 小窗只读”模式不点屏幕，但要求闲鱼窗口还露在屏幕上（视频小窗/分屏可以；游戏全屏时闲鱼不可见，就读不到）。

只有点「解析短链」时会联网 GET 一次 m.tb.cn，不传本机数据；正常观察不联网。
